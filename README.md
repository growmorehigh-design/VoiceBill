# Voice Bill — Tamil voice-la sonna bill ready (Non-GST Cash Bill)

## APK eppadi edukkuradhu (free, computer-la Android Studio vendaam)
1. github.com-la free account open pannunga → **New repository** → name: `VoiceBill` → Create.
2. "uploading an existing file" link click pannunga → intha zip-a extract panni, ulla irukkura
   **ella files + folders-ayum** (`.github` folder-um sethu) drag & drop pannunga → **Commit changes**.
3. Mela **Actions** tab → "Build APK" run aagum (~5 nimisham). Pachai ✔ vandha, adha click pannunga.
4. Keela **Artifacts → VoiceBill-APK** download → zip-kulla `VoiceBill.apk` irukkum.
5. Phone-ku anuppi install pannunga ("Install unknown apps" allow pannanum).

## App use panra murai
- Mudhal thadavai: ⚙ கடை → workshop name, address, phone → சேமி.
- Mic thatti: "கஸ்டமர் பெயர் திருப்பதி கேர், கிரேன் கேபின் வேலை செய்தது ஒரு செட் 25000,
  பின் புஷ் அடித்தது 5 நம்பர் 5000 ரூபாய்"
- Oru item oru thadavai-yum sollalaam — bill-la serndhukitte pogum.
- Thappa vandha box-la thottu thiruthalaam. Amount = andha line-oda motha thogai (Rate auto).
- **WhatsApp / Share** → bill image-a anuppum. **PDF / Print** → "Save as PDF" or printer.
- Units: set, nos/நம்பர், pcs, meter, litre, kg, hours, day, job, lot.
- "ரேட் 450" nu sonna qty × rate = amount.
- Voice-ku Google app venum (Tamil offline pack download panna internet illaama kooda work aagum).
